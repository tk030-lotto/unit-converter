# 単位変換ツール（Unit Converter）

長さ・面積・重さ・温度・燃費・日本の慣用単位など 16 カテゴリの単位を、ブラウザ上で相互変換できる Web ツールです。

## こんなときに

- 料理・買い物・DIY・部屋の間取り確認で、cm・m²・坪・畳などを換算したいとき
- 海外旅行や輸入品の確認で、inch・mile・lb・℉・gallon・mpg などを換算したいとき
- 学習や業務で、圧力・エネルギー・仕事率・周波数・角度・電気・データ容量・尺貫法を確認したいとき

## 主な機能

- **16 カテゴリの単位変換**: 長さ、面積、重さ・質量、体積、温度、速度、時間、データ容量、圧力、エネルギー、仕事率、周波数、角度、電気（電圧・電流・抵抗）、燃費、日本の慣用単位（長さ・面積・体積）
- **入力と同時の換算**: 「変換元」に数値を入力すると、そのまま「変換先」に結果が表示されます
- **単位の入れ替え**: 「⇅」を押すと、変換元と変換先の単位を入れ替え、直前の結果を「変換元」へ移します
- **結果のコピー**: 「📋 結果をコピー」を押すと変換結果をコピーできます（自動コピーできない環境では、手動コピー用の入力欄を表示します）
- **よく使う変換**: `m² ⇄ 坪`、`m² ⇄ 畳`、`km ⇄ mile`、`kg ⇄ lb`、`℃ ⇄ ℉`、`km/L ⇄ mpg` を 1 回押すだけで呼び出せます
- **規格・定義の注記表示**: 畳（江戸間）、米国液量、US mpg、固定暦日数など、基準によって差が出るカテゴリでは画面内に注記を表示します

### 対応カテゴリと単位一覧

| カテゴリ | 登録単位 | 換算仕様 |
| :--- | :--- | :--- |
| **長さ** | mm, cm, m, km, inch, ft, yd, mile, 海里 | 基準単位: `m` |
| **面積** | mm², cm², m², km², 坪, 畳, a, ha, acre | 基準単位: `m²`（坪 = 400/121 m²、畳は江戸間 1.5488 m²） |
| **重さ・質量** | mg, g, kg, t, oz, lb | 基準単位: `kg` |
| **体積** | mL, L, cm³, m³, fl oz, pint, quart, gallon | 基準単位: `L`（fl oz / pint / quart / gallon は米国液量定義） |
| **温度** | ℃ (摂氏), ℉ (華氏), K (ケルビン) | 温度専用の変換式で換算 |
| **速度** | m/s, km/h, mph, knot | 基準単位: `m/s` |
| **時間** | ms, 秒, 分, 時間, 日, 週, 月, 年 | 基準単位: `秒`（1月 = 30日、1年 = 365日の固定換算） |
| **データ容量** | bit, Byte, KB, MB, GB, TB, PB | 十進接頭辞（1 KB = 1000 Byte） |
| **圧力** | Pa, kPa, MPa, bar, atm, mmHg, psi | 基準単位: `Pa` |
| **エネルギー** | J, kJ, cal, kcal, Wh, kWh | 基準単位: `J`（1 cal = 4.184 J） |
| **仕事率** | W, kW, MW, hp | 基準単位: `W`（hp は英馬力: 1 hp = 745.699872 W） |
| **周波数** | Hz, kHz, MHz, GHz | 基準単位: `Hz` |
| **角度** | 度 (°), rad (ラジアン), grad (グラード) | 基準単位: `度 (°)` |
| **電気** | 電圧 (V, mV, kV)、電流 (A, mA)、抵抗 (Ω, kΩ, MΩ) | 物理量ごとのタブで切替 |
| **燃費** | km/L, L/100km, mpg (US) | 逆数関係を含む燃費専用の変換式（mpg は米国ガロン基準） |
| **日本の慣用単位** | 長さ（尺, 寸, 間, 町, m）、面積（坪, 畳, 畝, 反, 町, m²）、体積（勺, 合, 升, 斗, 石, L） | 尺貫法の法定換算率および畳（江戸間: 1.5488 m²） |

## 使い方

### ブラウザで使う

1. [ツールを開く](https://zero-dev.jp/unit-converter/) をクリックします。
2. 「変換カテゴリ」から、使いたいカテゴリを選びます。
3. 必要なら、電気や日本の慣用単位では表示されたタブ（「電圧」「電流」「抵抗」など）を押して種類を選びます。
4. 「変換元」の数値欄に、変換したい半角の数字を入力します。
5. 必要なら、「変換元」と「変換先」の単位を選びます（よく使う組み合わせは「よく使う変換」のボタンから 1 回で選べます）。
6. 「変換先」の欄に、計算結果が表示されます。
7. 必要なら、「⇅」を押して単位を入れ替えるか、「✕ クリア」で入力を消します。
8. 「📋 結果をコピー」を押すと、変換結果がコピーされ、画面下に通知が出ます。

### パソコンに保存して使う（ローカル環境）

1. このリポジトリをダウンロードし、フォルダを開きます。
2. Windows の場合は、付属の `ツール起動.bat` を実行します（ローカルサーバーが起動し、`http://localhost:8000` がブラウザで開きます）。

## うまくいかないとき

- **結果が「—」のままエラーが出る**: 半角の数字（例: `100`、`-12.5`）で入力してください。全角数字や文字は変換できません。燃費カテゴリでは `0` より大きい数値を入力してください。
- **「📋 結果をコピー」で自動コピーできない**: ブラウザの権限や環境によっては自動コピーできない場合があります。画面内に手動コピー用の入力欄が表示されるため、選択状態の結果を手動でコピーしてください。
- **パソコン上で `index.html` を直接開いても動かない**: ES Modules を使用しているため、`file://` ではブラウザの制限により動作しません。`ツール起動.bat` またはローカル HTTP サーバー経由で開いてください。

## 動作環境

- Google Chrome、Microsoft Edge、Apple Safari、Mozilla Firefox の各最新版
- PC およびスマートフォン（iOS Safari / Android Chrome）の画面幅に対応

## 制限・注意

- 計算結果は倍精度浮動小数点で計算し、有効桁数 8 桁で丸めて表示します（極大・極小値は指数表記になります）。
- 桁区切りカンマ付きの表示文字列がそのままコピーされます（本ツールの入力欄へ再貼り付けした場合はカンマを自動除去して計算します）。
- 地域や規格により定義が異なる単位（畳、ガロン、mpg、馬力、1か月・1年の日数）は、画面内の注記および上記の換算仕様に示した定義で計算します。
- 入力内容や履歴をブラウザやサーバーへ保存する機能はありません。ページを再読み込みすると初期状態に戻ります。

## 外部通信

- 外部サーバーへの通信は行いません。入力値と計算処理はすべてブラウザ内で完結します。
- 外部フォントや外部 CDN は読み込んでいません（Chromium / WebKit で外部リクエスト 0 件を確認、`Content-Security-Policy` で `connect-src 'none'` を設定済み）。
- フッターには [zero-dev.jp](https://zero-dev.jp/) へのリンクのみを配置しています。
